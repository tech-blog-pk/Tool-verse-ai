Hackers Broke OpenAI Codex With a Single Bug at Pwn2Own Ireland 2026

TV
ToolVerse AI
ToolVerse AI Contributor
📅 Oct 9, 2026⏱ 7 min read
🔓

On October 6, 2026, the first day of the Pwn2Own Ireland 2026 hacking competition in Cork, security researchers demonstrated 32 unique zero-day exploits across phones, smart home devices, printers, and AI platforms — walking away with a combined $388,500 in prize money. Among the targets: OpenAI's cloud-based coding agent, Codex, which a team called Ikotas Labs took down using just a single argument-injection bug, earning $40,000 for the find.

💡
Quick summary: Pwn2Own Ireland 2026's opening day produced 32 zero-day vulnerabilities across eight products, including three AI-related ones: OpenAI Codex, the Oracle Autonomous AI Database, and LiteLLM. OpenAI Codex fell to a single, relatively simple bug. Affected vendors now have a 90-day window to patch before details go public.

What Is Pwn2Own, and Why Does It Matter?

Pwn2Own is a hacking competition organized by the Zero Day Initiative (ZDI), a division of Trend Micro. Security researchers and teams compete to find and demonstrate working exploits against real, up-to-date products — phones, routers, printers, smart home devices, and increasingly, AI tools. The goal isn't malicious: ZDI's entire model is built around finding these bugs before criminals do, then giving vendors a 90-day window to patch them before any technical details are published.

This year's Ireland event ran from October 6–9, 2026, with entries across seven categories. Day one alone produced a contest-record eight successfully hacked products and 32 unique zero-days — a notable jump in how many entries targeted AI infrastructure specifically.

How OpenAI Codex Was Broken

Codex, OpenAI's cloud-based AI coding agent, was compromised using a single argument-injection vulnerability — a type of bug where an attacker manipulates the parameters passed into a command or function to make it behave in unintended ways. Notably, this wasn't a complex, multi-stage chain like some of the other exploits at the event; it took just one bug to win. The Ikotas Labs team earned $40,000 and additional "Master of Pwn" points for the result, one of the single largest payouts of the day.

Codex wasn't the only AI platform to fall. A team working under the name Xint successfully exploited LiteLLM — a widely used open-source library that lets developers call dozens of different AI models through one unified interface — by combining an input-validation flaw with code injection. Separately, the VinSOC team chained five vulnerabilities to break into the Oracle Autonomous AI Database, winning another $40,000.

The Rest of Day One

AI tools weren't the only targets. Researchers also hacked the Samsung Galaxy S26 twice, broke into a Philips Hue Bridge Pro smart lighting hub using a seven-bug exploit chain, compromised Lexmark and Canon multifunction printers, and took down a Sonos Era 300 smart speaker using four separate vulnerabilities. A researcher's attempt against the Garmin Index BPM smart blood pressure monitor was the only unsuccessful entry of the day.

Why This Matters: AI Tools Are Now a Real Attack Surface

What stands out about this year's results is how central AI products have become to the competition itself. Three of the day's eight successful targets — Codex, LiteLLM, and the Oracle AI Database — were AI-related, reflecting how deeply these tools are now embedded in everyday developer and enterprise workflows. The fact that Codex fell to a single, relatively straightforward bug is a reminder that AI agents with the ability to execute code or take real actions carry real, concrete security risk — not just theoretical "AI safety" concerns, but the same kind of exploitable software bugs found in any other product.

This fits a pattern ToolVerse AI has covered throughout the year: AI coding agents and platforms increasingly handling real permissions and real infrastructure, and security researchers, regulators, and attackers all racing to find where those systems break first.

What Happens Next

All affected vendors — including OpenAI, Oracle, the LiteLLM maintainers, Samsung, Philips, Lexmark, Canon, and Sonos — now have ZDI's standard 90-day disclosure window to issue patches before technical details of each exploit are made public. Until patches ship, specifics of how each bug works are being kept confidential, which is standard practice for responsible disclosure.

FAQ — Pwn2Own Ireland 2026 and the OpenAI Codex Exploit

Is OpenAI Codex safe to use right now?

The specific bug used to exploit Codex hasn't been publicly disclosed, and OpenAI has a 90-day window to patch it before details are released — so there's no public, usable exploit circulating as of this writing.

What is an "argument-injection" bug?

It's a vulnerability where an attacker manipulates the parameters (arguments) passed into a command or function, tricking the system into executing unintended actions — often simpler to pull off than a multi-step exploit chain.

Were other AI tools affected besides Codex?

Yes — LiteLLM (a popular library for routing requests across multiple AI models) and the Oracle Autonomous AI Database were also successfully exploited on the same day.

How much money did researchers win in total?

Day one of Pwn2Own Ireland 2026 produced $388,500 in total payouts across all 32 zero-day exploits.

When will the technical details of these bugs be published?

Following Pwn2Own's standard 90-day responsible disclosure window, giving vendors time to ship patches first.

Conclusion

A single bug taking down OpenAI's flagship coding agent at a major public hacking contest is a concrete data point in a year full of AI-security headlines — proof that as AI agents get more capable and more widely deployed, they're also becoming a bigger, more attractive target. For developers and companies building on tools like Codex, the takeaway isn't to panic, but to treat AI agent security with the same seriousness as any other piece of critical infrastructure — because that's exactly how attackers, and researchers, are starting to treat it. 🔓
